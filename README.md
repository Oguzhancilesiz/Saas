# Saas (arşiv)

Çok uygulamalı abonelik altyapısı için ilk deneme: Clean Architecture (Domain / Application / Infrastructure), MediatR, FluentValidation, JWT, Redis, rate limiting.

Bu repo arşivlendi. Fikrin geliştirilmiş hali:

- [SaasTool](https://github.com/Oguzhancilesiz/SaasTool): .NET 9 API + Next.js admin paneli
- [SaasV2](https://github.com/Oguzhancilesiz/SaasV2): webhook'lar, kullanım ölçümü ve Outbox deseniyle yeniden tasarım
